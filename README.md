# Corporate Avatar: Off Duty

A public event site for **Corporate Avatar: Off Duty**, a 24-hour New York experience about clothing, identity, work, culture, and the parts of ourselves that do not clock out.

## Event

- **Location:** New York City
- **Format:** In person + broadcast
- **Program:** Four chapters moving from first light to after hours
- **Partner:** [GoodHeart](https://www.goodheartapp.com/)

## Development

This site is built with Next.js, React, TypeScript, and CSS. Start the development server with:

```bash
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).
