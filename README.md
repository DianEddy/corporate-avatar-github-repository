**A 24-hour New York experience about clothing, identity, work, and the selves we carry beyond the clock.**

This repository is the public project desk for **Corporate Avatar: Off Duty** — a shared reference point for people who want to join the team, shape the program, explore a partnership, or follow the work as it develops.

## Get involved

We are currently welcoming thoughtful collaborators, participants, makers, vendors, production partners and aligned sponsors. Read the relevant opportunity page first, then start a conversation at **edidirect@edimassive.com**.

Please do not submit confidential information, personal documents, private contact details or unreleased work through public issues or pull requests.
